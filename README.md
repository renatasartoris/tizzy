# tizzy

NŌMA — Good in. Great out.

Experiência interativa de nutrição com Three.js e GSAP. Esta publicação preserva a primeira versão, com a lata 3D.

## Publicação

GitHub Pages: https://renatasartoris.github.io/tizzy/

O arquivo `index.html` reúne o HTML, o CSS, o JavaScript e a imagem de fallback. A tipografia é carregada pelo Google Fonts. Os valores nutricionais são demonstrativos.

Para visualizar localmente, abra `index.html` em um navegador.
